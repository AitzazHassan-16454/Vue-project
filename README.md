# 📊 Nexus Analytics — Enterprise SaaS & Financial Dashboard

A modern, production-ready SaaS Analytics and Financial Intelligence platform built with **Vue 3**, **TypeScript**, **Vite**, **Tailwind CSS**, **Pinia**, and **Chart.js**.

---

## 🚀 Key Highlights

* **Enterprise UI/UX:** Clean SaaS aesthetic with light/dark theme toggle, responsive collapsible navigation, and accessible layout.
* **Interactive Data Visualizations:** Real-time revenue analytics, growth curves, and expense breakdown powered by Chart.js.
* **Smart Financial Ledger:** Transaction management with live debounced search, status filtering, and one-click CSV export.
* **AI Financial Insights Copilot:** Contextual financial summaries, trend detection, and automated commentary.
* **100% Free Serverless Deployment:** Ready for one-click deployment on **Vercel** or **Netlify** with zero hosting costs and free SSL.

---

## 🛠️ Tech Stack

* **Framework:** Vue 3 (`<script setup>` Composition API)
* **Build System:** Vite 8
* **Styling:** Tailwind CSS v4
* **State Management:** Pinia with LocalStorage Persistence
* **Routing:** Vue Router
* **Visualizations:** Chart.js & Vue-ChartJS
* **Icons:** Lucide Icons (`@lucide/vue`)
* **Utilities:** VueUse (`@vueuse/core`)

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/AitzazHassan-16454/Vue-project.git

# Enter project directory
cd Vue-project

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Free Deployment (Vercel)

This project is configured for instantaneous deployment on **Vercel** or **Netlify**:
1. Connect your GitHub repository to Vercel.
2. Framework preset will automatically detect **Vite**.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Click **Deploy** to receive your free `*.vercel.app` URL with SSL!
